# Custom Software

Custom software developed for the RC plane telemetry project
will be stored here.

Initially, the system will use:

- ArduPlane on the flight controller
- MAVLink for telemetry
- Mission Planner on the ground station

Custom software will only be developed if required.

Possible future software:

- MAVLink data receiver
- Flight data analysis
- Telemetry visualization
- Automated test tools
